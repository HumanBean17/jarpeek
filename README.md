# jarpeek

Context-frugal navigation into JVM dependency sources, for AI agents.

This repo is a workspace: the publishable npm package lives in [`jarpeek/`](jarpeek/).
All documentation — install, CLI and MCP usage, architecture — is in
**[jarpeek/README.md](jarpeek/README.md)**. The README stays there because
`npm publish` ships it from the package root.

| Path | What it is |
| --- | --- |
| [`jarpeek/`](jarpeek/) | The npm package: source, tests, docs, packaging |
| [`docs/`](docs/) | Project docs and archived specs |
